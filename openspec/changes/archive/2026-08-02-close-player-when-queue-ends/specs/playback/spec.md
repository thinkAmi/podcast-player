# playback Spec Delta

## MODIFIED Requirements

### Requirement: ミニプレイヤーとプレイヤー画面
再生中は一覧系画面の下部にミニプレイヤー(エピソード名・再生/一時停止)を表示し、タップでプレイヤー画面を開くものとする(SHALL)。プレイヤー画面はアートワーク・シークバー・再生/一時停止・前後10秒スキップ・速度変更・再生中エピソードのショーノートを表示する。

プレイヤー画面を表示中に再生キューが空になったとき(キュー終端まで鳴り切ったとき)、プレイヤー画面は自動で閉じ、開く前の画面へ戻るものとする(SHALL)。自動で閉じる判定は再生状態のエピソード ID が非null から null へ遷移したことによるものとし(SHALL)、エピソード間の自動継続再生や controller 再接続直後の初期状態で閉じてはならない(MUST NOT)。ユーザーの閉じる操作と自動クローズが競合しても、閉じる動作は一度だけ実行され、プレイヤー画面より下の画面まで閉じてはならない(MUST NOT)。

#### Scenario: ミニプレイヤーからの遷移
- **WHEN** 一覧画面でミニプレイヤーをタップする
- **THEN** プレイヤー画面が開き、シークバー・速度・ショーノートが表示される

#### Scenario: キューを聴き終えるとプレイヤー画面が閉じる
- **WHEN** プレイヤー画面を開いたまま、キュー末尾のエピソードが最後まで鳴り切る
- **THEN** プレイヤー画面が自動で閉じて元の一覧画面へ戻り、ミニプレイヤーも表示されない

#### Scenario: 自動継続再生では閉じない
- **WHEN** プレイヤー画面を開いたまま、エピソードが終わり次のDL済みエピソードへ自動で進む
- **THEN** プレイヤー画面は開いたまま、次のエピソードのタイトルとショーノートに切り替わる

#### Scenario: 画面回転で閉じない
- **WHEN** 再生中にプレイヤー画面を開いたまま画面を回転する
- **THEN** プレイヤー画面は開いたままで、再生中のエピソードが表示され続ける

#### Scenario: 閉じる操作と競合しても一覧画面より下へは戻らない
- **WHEN** キュー末尾が鳴り切るのとほぼ同時にユーザーが閉じるボタンをタップする
- **THEN** プレイヤー画面が閉じて直下の一覧画面が表示される(一覧画面まで閉じてしまわない)

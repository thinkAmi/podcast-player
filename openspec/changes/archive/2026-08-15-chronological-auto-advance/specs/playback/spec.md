# playback 差分仕様

## ADDED Requirements

### Requirement: 時系列順の自動継続再生
エピソードの再生が末尾まで達したとき、公開日時の古い順(古→新)で次のDL済みエピソードを自動再生するものとする(SHALL)。再生キューは、再生開始時に現在のエピソード一覧(フィルター適用後)から「開始エピソードと、それより新しいDL済みエピソード」を古→新の順に並べて構築する(SHALL)。開始エピソードより古いエピソードをキューに含めてはならない(MUST NOT)。未DLのエピソードはスキップし、ダウンロードを自動開始してはならない(MUST NOT)。次のDL済みエピソードがなければ、再生を停止しプレイヤーを空に戻すものとする(SHALL)。空に戻った状態では「現在のエピソード」は存在せず、メディア通知とミニプレイヤーは表示されない。

#### Scenario: より新しいDL済みエピソードへの継続
- **WHEN** 再生中のエピソードが終了し、それより新しいDL済みエピソードが存在する
- **THEN** そのうち最も古いエピソードの再生が自動的に開始される

#### Scenario: 未DLエピソードのスキップ
- **WHEN** 時系列順で次のエピソードが未DLで、その次(さらに新しい側)がDL済みである
- **THEN** 未DLをスキップしてDL済みエピソードが再生され、通信は発生しない

#### Scenario: 最新まで聴き終えた
- **WHEN** 開始エピソードより新しい側にDL済みエピソードが存在しない状態で、再生中のエピソードが末尾まで達する
- **THEN** 再生は停止し、プレイヤーは空に戻る。メディア通知とミニプレイヤーが消える

#### Scenario: 開始エピソードより古い回は再生されない
- **WHEN** 開始エピソードより古いDL済みエピソードが存在する状態で再生を開始し、キューの最後まで聴き終える
- **THEN** 古い回が自動再生されることはなく、プレイヤーは空に戻る

#### Scenario: 聴き終えた後の行はダウンロードアイコンに戻る
- **WHEN** キューの最後のエピソードを聴き終え、視聴済み化によってDLファイルが自動削除される
- **THEN** そのエピソードの行は「現在のエピソード」ではなくなり、ダウンロードアイコンが表示される(再ダウンロードして聴き直せる)

## MODIFIED Requirements

### Requirement: 統合エピソード画面
エピソードごとの画面は1枚の統合エピソード画面とする(SHALL)。エピソード一覧の行本文タップ、およびミニプレイヤーのタップ(現在のエピソードの画面が開く)から到達する。画面はタイトル・ショーノート・番組アートワーク・視聴済みトグルを常に表示し、エピソードの状態に応じたアクションを表示するものとする(SHALL):

- 現在のエピソード(再生キューがいま指しているエピソード): シークバー・再生/一時停止・前後10秒スキップ・速度変更のフルコントロール
- DL済み(現在のエピソードではない): 再生ボタン。タップでエピソード一覧と同じ規則(フィルター適用後の一覧から時系列順=古→新)により再生キューを構築して再生を開始する
- DL中: 進捗表示
- DL失敗: エラー表示。タップで再試行
- 未DL: DLボタン

状態に応じたアクションの判断はエピソード一覧の行アイコンと同じ規則を共有し、両者で挙動が異なってはならない(MUST NOT)。

#### Scenario: 現在のエピソードを開く
- **WHEN** 再生中のエピソードの統合エピソード画面を開く(行本文タップまたはミニプレイヤータップ)
- **THEN** アートワーク・シークバー・再生/一時停止・前後10秒スキップ・速度変更・ショーノートが表示される

#### Scenario: DL済みエピソードを開いて再生を開始する
- **WHEN** DL済み(非再生中)エピソードの統合エピソード画面で再生ボタンをタップする
- **THEN** フィルター適用後の一覧から時系列順(古→新)の再生キューが構築されて保存位置から再生が始まり、画面はフルコントロール表示に切り替わる

#### Scenario: 未DLエピソードを開く
- **WHEN** 未DLエピソードの統合エピソード画面を開く
- **THEN** タイトル・ショーノート・アートワークとDLボタンが表示され、再生コントロールは表示されない

#### Scenario: フィルターで除外されたエピソードの再生
- **WHEN** 現在のフィルターで一覧に表示されないエピソードの統合エピソード画面で再生ボタンをタップする
- **THEN** 再生は開始されず、案内メッセージが表示される(一覧の既存フォールバックと同種の振る舞い)

### Requirement: 現在のエピソード行の再生/一時停止トグル
エピソード一覧において、現在のエピソードの行のアイコンは再生状態を表示するものとする(SHALL): 再生中は一時停止アイコン、一時停止中は再生アイコン。この行のアイコンのタップは再生/一時停止のトグルであり(SHALL)、再生キューの再構築および再生位置のシークを行ってはならない(MUST NOT)。現在のエピソードか否かの判定は、行のエピソード ID と再生状態のエピソード ID の一致による。

#### Scenario: 再生中の行を一時停止する
- **WHEN** 再生中のエピソードの行の一時停止アイコンをタップする
- **THEN** 再生が一時停止し、行とミニプレイヤーのアイコンがともに再生アイコンに変わる

#### Scenario: 一時停止中の行を再開する
- **WHEN** 一時停止中の現在のエピソードの行の再生アイコンをタップする
- **THEN** その位置から再生が再開される。再生キューは組み直されず、再生位置もシークされない

#### Scenario: 別の行は従来どおり開始として振る舞う
- **WHEN** 再生中に、現在のエピソードではないDL済みエピソードの再生アイコンをタップする
- **THEN** フィルター適用後の一覧から時系列順(古→新)の新しい再生キューが構築され、そのエピソードの保存位置から再生が始まる

#### Scenario: 自動で次のエピソードへ進んだとき
- **WHEN** 現在のエピソードが最後まで鳴り切り、キューが次(より新しい側)のエピソードへ自動で進む
- **THEN** 一時停止アイコンの表示は次のエピソードの行へ移る

#### Scenario: 現在のエピソードがこの一覧にないとき
- **WHEN** 別のフィードのエピソードを再生しながら、この一覧を表示する
- **THEN** この一覧のすべての行は開始として振る舞い、一時停止アイコンはどの行にも表示されない

## REMOVED Requirements

### Requirement: リスト順の自動継続再生
**Reason**: 自動継続の向きが利用者の聴き方(古い回から新しい回へ)と逆だった。「時系列順の自動継続再生」要件に置き換える。
**Migration**: 動作仕様は「時系列順の自動継続再生」を参照。未DLスキップ・自動DL禁止・終端で停止しプレイヤーを空に戻す規則は新要件に引き継がれている。

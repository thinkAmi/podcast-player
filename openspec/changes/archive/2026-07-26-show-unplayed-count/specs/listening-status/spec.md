# listening-status Delta: show-unplayed-count

## ADDED Requirements

### Requirement: 購読一覧での未聴数表示
購読一覧の各番組行に、その番組の未聴エピソード数を数字で表示するものとする(SHALL)。未聴数は「視聴済みでない(played=0)エピソードの全件数」であり、番組ごとに保存された絞り込み条件(未聴のみ/DL済みのみ)には依存しない(SHALL)。未聴数が 0 件の番組には数字を表示しない(SHALL)。数字は丸めずそのまま表示する(SHALL)。この表示のための通信・並び順の変更・設定項目を追加しない(MUST NOT)。

#### Scenario: 未聴ありの番組
- **WHEN** 未聴エピソードが10件ある番組が購読一覧に表示される
- **THEN** その番組の行に「10」が表示される

#### Scenario: 全件視聴済みの番組
- **WHEN** 全エピソードが視聴済みの番組が購読一覧に表示される
- **THEN** その番組の行に未聴数は表示されない(バッジ自体が出ない)

#### Scenario: 保存フィルターに依存しない
- **WHEN** 「DL済みのみ」フィルターを保存した番組に、未DLの未聴エピソードが10件ある
- **THEN** 購読一覧の未聴数は10と表示される(フィルターを通した件数ではない)

#### Scenario: 視聴状態の変更が即時反映される
- **WHEN** エピソードを視聴済みにする(個別トグル・一括変更・再生完了の自動判定のいずれか)
- **THEN** 購読一覧に戻ったとき、その番組の未聴数は減っている(未聴に戻せば増える)

#### Scenario: 大きな未聴数の表示
- **WHEN** 未聴エピソードが347件ある番組が購読一覧に表示される
- **THEN** 「347」がそのまま表示される(「99+」等への丸めは行わない)

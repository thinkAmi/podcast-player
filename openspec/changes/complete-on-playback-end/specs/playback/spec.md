# playback Delta

## MODIFIED Requirements

### Requirement: リスト順の自動継続再生
エピソードの再生が末尾まで達したとき、現在のエピソード一覧(フィルター適用後)の並び順で次のDL済みエピソードを自動再生するものとする(SHALL)。未DLのエピソードはスキップし、ダウンロードを自動開始してはならない(MUST NOT)。次のDL済みエピソードがなければ、再生を停止しプレイヤーを空に戻すものとする(SHALL)。空に戻った状態では「現在のエピソード」は存在せず、メディア通知とミニプレイヤーは表示されない。

#### Scenario: 次のDL済みエピソードへの継続
- **WHEN** 再生中のエピソードが終了し、リスト順で次にDL済みエピソードが存在する
- **THEN** そのエピソードの再生が自動的に開始される

#### Scenario: 未DLエピソードのスキップ
- **WHEN** リスト順で次のエピソードが未DLで、その次がDL済みである
- **THEN** 未DLをスキップしてDL済みエピソードが再生され、通信は発生しない

#### Scenario: 継続先がない
- **WHEN** リスト順で以降にDL済みエピソードが存在しない状態で、再生中のエピソードが末尾まで達する
- **THEN** 再生は停止し、プレイヤーは空に戻る。メディア通知とミニプレイヤーが消える

#### Scenario: 聴き終えた後の行はダウンロードアイコンに戻る
- **WHEN** キューの最後のエピソードを聴き終え、視聴済み化によってDLファイルが自動削除される
- **THEN** そのエピソードの行は「現在のエピソード」ではなくなり、ダウンロードアイコンが表示される(再ダウンロードして聴き直せる)

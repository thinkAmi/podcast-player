name: add-podcast-feed
description: podcast-player に RSS フィードを PC から購読登録する。ユーザーが「このフィードを登録して」「このポッドキャストを追加して」と RSS の URL を渡してきたとき、または PC から購読を追加したいときに使用する。
---

`scripts/add-feed.sh` を実行してください。それだけです。

```bash
./scripts/add-feed.sh <RSS の URL>
```

URL は引数として 1 つずつ渡します。複数登録するときはスクリプトを複数回実行してください。

## adb コマンドを自分で組み立てないこと

このスキルの目的は、登録手順を毎回組み立て直さないことにあります。コンポーネント名・
extra キー・`--user 0` の要否・端末側シェルのクォート・結果コードの意味はすべて
アプリ側の `AdbFeedReceiver` との契約であり、スクリプトが一元的に持っています。

`adb shell am broadcast ...` を直接実行してはいけません。契約の記憶違いや
クォート漏れ(`&` を含む URL が途中で切れる)が起きます。スクリプトが動かない場合は、
回避策を即興で組み立てるのではなく、エラーメッセージをそのままユーザーに伝えてください。

## 結果の読み方

スクリプトの出力をそのまま伝えれば十分です。終了コード 0 が登録成功、それ以外は失敗で、
理由は標準エラーに出ます。よくある失敗:

- `https:// の URL を指定してください` — 登録できるのは https のみ
- `端末が接続されていません` — USB 接続と USB デバッグ許可を確認する
- `届きましたが登録できませんでした: ...` — 端末までは届いたが購読できなかった
  (到達不能・ポッドキャストの RSS ではない・すでに購読済み、など理由が続く)
- `Receiver に届きませんでした` — アプリが古い可能性がある(`./gradlew installDebug`)
